DC+SYNC
ET1100 的 DC+SYNC 功能测试核心是：先完成 DC 时钟同步校准，再配置 SYNC0/SYNC1 周期与触发，最后通过寄存器状态、示波器 / 逻辑分析仪验证同步精度与信号时序。以下是完整配置流程、寄存器明细与测试方法。

一、测试前准备
硬件环境
主站：Beckhoff TwinCAT/SOEM/IGH EtherCAT 主站
从站：ET1100 ESC（外接 25MHz 晶振，确保 DC 时钟源稳定）
测试工具：示波器 / 逻辑分析仪（测 SYNC0/SYNC1 信号）、主站调试工具（如 TwinCAT System Manager）
网络：标准 EtherCAT 总线，首尾接 110Ω 终端电阻
关键概念
DC（分布式时钟）：实现从站间亚微秒级时间同步（<100ns）
SYNC0/SYNC1：ET1100 输出两路周期性同步脉冲，用于触发应用、IO 采样 / 更新、中断
核心寄存器区：0x0900–0x09FF（DC 控制）、0x0140/0x0151（SYNC 引脚使能）

二、DC+SYNC 配置全流程（寄存器 + 步骤）
阶段 1：DC 时钟基础使能（必须先做）
使能 DC 单元（0x0140）
地址：0x0140（ESC 配置寄存器）
位 10（DC Sync Unit）：1（使能 DC 同步单元）
位 11（DC Latch Unit）：1（可选，使能 Latch 时间戳）
写入值示例：0x0C00（仅 DC Sync+Latch 使能，其他位默认）
配置 SYNC 引脚方向（0x0151）
地址：0x0151（DC SYNC/LATCH 配置）
位 0：1（SYNC0 为输出）
位 1：1（SYNC1 为输出）
写入值：0x03（两路均为 SYNC 输出）
主站发起 DC 同步校准（3 步）
传播延迟测量
主站发 BWR 到 0x0900（端口 0 接收时间），从站锁存各端口接收时间
主站读取 0x0900–0x090F（端口 0–3 接收时间），计算链路延迟
写入0x0928–0x092B（系统时间延迟），补偿物理延迟
偏移补偿
主站计算从站本地时钟与参考时钟的偏移
写入0x0920–0x0927（系统时间偏移），对齐系统时间
漂移补偿
主站周期性发 ARMW/FRMW，更新从站系统时间
校准0x0932–0x0933（速度计数器差），稳定时钟频率
验证 DC 同步状态
读0x092C–0x092F（系统时间差）：值 < 100ns 表示 DC 已锁定
读0x0932–0x0933（速度计数器差）：稳定在小范围表示漂移补偿完成

阶段 2：SYNC0/SYNC1 详细配置（核心）
配置 SYNC 脉冲长度（0x0982–0x0983）
地址：0x0982（低 16 位）、0x0983（高 16 位）
单位：ns，建议1000–10000ns（避免过窄无法检测）
示例：1µs → 写入0x03E8（0x0982）、0x0000（0x0983）
分配 SYNC 控制源（0x0980）
地址：0x0980（DC 循环单元控制）
位 0：0（SYNC 由 ECAT 主站控制，推荐）
位 1：0（SYNC0/1 同控制源）
写入值：0x00
设置 SYNC 周期（0x09A0–0x09A7）
SYNC0 周期（0x09A0–0x09A3）：32 位，单位 ns
示例：1ms → 0x000F4240
SYNC1 周期（0x09A4–0x09A7）：32 位，单位 ns
示例：与 SYNC0 同周期 → 同值；半周期 → 0x0007A120
设置 SYNC 启动时间（0x0990–0x0997）
地址：0x0990–0x0997（64 位系统时间）
写入当前系统时间 + 偏移（如 + 10ms），确保激活后立即触发
示例：读 0x0910–0x0917（系统时间）+ 10,000,000ns → 写入
激活 SYNC 生成（0x0981，最关键）
地址：0x0981（DC 激活寄存器）
位 0（Cyclic Operation）：1（启动周期运行）
位 1（SYNC0 Enable）：1（使能 SYNC0）
位 2（SYNC1 Enable）：1（使能 SYNC1）
写入值：0x07（激活循环 + SYNC0+SYNC1）

阶段 3：SYNC 触发模式与应用绑定（可选）
同步 IO 采样 / 更新（数字 IO PDI）
输入采样：配置 SM 为SYNC0 触发采样（0x0807[3:2] = 0x01）
输出更新：配置 SM 为SYNC1 触发更新（0x080F[3:2] = 0x02）
确保 0x0440（过程数据看门狗） 使能或禁用
同步中断（映射到 PDI IRQ）
0x0220–0x0223（AL 事件请求）：映射 SYNC0 事件到中断位
0x0150（PDI 配置）：使能 PDI IRQ 输出

验证指标
周期精度：SYNC0/SYNC1 周期与配置值一致（如 1ms）
脉冲宽度：与 0x0982–0x0983 配置一致（如 1µs）
同步抖动：多从站 SYNC0 边沿对齐，抖动 < 15ns（ET1100 规格）
相位关系：SYNC1 相对 SYNC0 的偏移符合配置
应用层同步验证
多从站同一 SYNC 触发下，IO 采样 / 输出同时性
中断触发时间一致性，无明显错位

四、常见问题与排查
SYNC 无输出
检查 0x0140 [10]、0x0151 [0:1]、0x0981 是否正确使能
确认 DC 已同步（0x092C–0x092F <100ns）
检查 SYNC 引脚是否配置为输出（0x0151）
SYNC 周期不准 / 抖动大
校准 DC 传播延迟与偏移（0x0928、0x0920）
确保 25MHz 晶振稳定，电源无噪声
增大 SYNC 脉冲长度，避免检测误差
从站不同步
主站重新发起 DC 校准（延迟 + 偏移 + 漂移）
检查网络拓扑，确保无环路、终端电阻正确
